# Feature Workflow

1. Classify task.
2. Create runtime state.
3. Planner.
4. Architect/debater for medium/complex/high-risk work.
5. QA Lead and Test Designer.
6. Developer.
7. API/UI/automation execution as applicable.
8. Failure Analyzer on failures.
9. Debugger + Developer repair loop, max 3 iterations.
10. Regression.
11. Code Review.
12. Security Review when risk/scope requires it.
13. Performance Review when applicable.
14. Release Gate.
