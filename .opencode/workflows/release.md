# Release Workflow

1. Verify requirements coverage.
2. Verify critical/high-risk tests.
3. Verify regression evidence.
4. Review known defects.
5. Review code findings.
6. Review security findings.
7. Review performance risks when applicable.
8. Decide:
   - PASS
   - PASS_WITH_RISK
   - BLOCKED
9. If production impact is high/critical, require human approval.
